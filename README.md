# Coffee Mall

Сайт кофейни с доставкой: каталог, окно покупки, корзина, оформление заказа, карта с зоной доставки и страница настройки
для владельца. Прототип без сервера: данные лежат в файле и в браузере, оплата имитируется.

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Сайт откроется на `http://localhost:5180`:

- `/` — главная;
- `/order/` — оформление заказа;
- `/admin/` — настройка (ссылки на неё с сайта нет, пароля тоже нет).

Сборка для хостинга — статические файлы в `dist/`:

```bash
npm run build
```

Тесты расчётов (корзина, доставка, маска телефона, зона):

```bash
npm test
```

## Карта

Нужны ключи из [кабинета разработчика Яндекса](https://developer.tech.yandex.ru). Скопируйте `.env.example` в
`.env.local`, впишите значения и перезапустите `npm run dev`.

| Переменная | Продукт в кабинете | Зачем |
|---|---|---|
| `VITE_YMAPS_KEY` | JavaScript API | карта, редактор зоны |
| `VITE_YGEOCODER_KEY` | API Геокодера | проверка адреса на зону доставки |
| `VITE_YSUGGEST_KEY` | API Геосаджест | подсказки при вводе адреса, необязателен |

В настройке первого ключа, в поле «Ограничение по HTTP Referer», должны стоять `localhost` и домен сайта — без этого
карта версии 3 не загрузится. Ключ начинает работать примерно через 15 минут.

Без ключа на месте карты стоит заглушка, а оформление заказа проверкой адреса не блокируется.

Условия бесплатного ключа: 1 000 проверок адреса и 1 000 подсказок в сутки; логотип и копирайт на карте закрывать
нельзя; найденные координаты нельзя сохранять и нужно показывать на карте Яндекса — поэтому на странице оформления
под адресом появляется небольшая карта.

## Данные и настройка

Опубликованная версия сайта — `public/data/store.json`: категории, товары, допы, условия и зона доставки, контакты.

Правки на странице `/admin/` сохраняются в браузере владельца (IndexedDB) и сразу видны на сайте, но только на этом
устройстве. Чтобы их увидели все:

1. «Данные» → «Скачать store.json».
2. Заменить этим файлом `public/data/store.json`.
3. Собрать и выложить сайт заново.

Загруженные владельцем фото хранятся внутри `store.json`.

Корзина лежит в `localStorage` и общая для главной и страницы оформления.

## Фото

Исходники — в `images/`. Сайт берёт лёгкие копии из `public/images/`; после замены или добавления исходника:

```bash
npm run images
```

Обрезать фото под карточку не нужно: рамка со скруглением обрезает любое изображение сама, масштаб задаётся у товара.

## Чего в прототипе нет

- Сервера: заказы никуда не отправляются, у `/admin/` нет входа.
- Платёжной системы: кнопка «Оформить заказ» открывает окно-заглушку, место подключения — функция `pay` в
  `src/screens/OrderScreen.jsx`.
- Текстов политики конфиденциальности и пользовательского соглашения: ссылки в подвале и под итогом никуда не ведут.
- Настоящих ссылок на соцсети: задаются в настройке, «Контакты».
